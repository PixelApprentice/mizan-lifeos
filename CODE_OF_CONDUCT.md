# Code of Conduct

Mizan adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. In short:

- Be respectful and welcoming, whatever someone's background, identity, experience or beliefs.
- Disagree about ideas, not people. Give and accept constructive feedback gracefully.
- Harassment, insults, sexualised language, publishing others' private information, and sustained disruption are not acceptable.

The code applies in all project spaces (issues, pull requests, discussions and chat) and when you represent the project in public.

**Reporting:** email conduct@<your-domain> (maintainer: set before publishing). Reports are handled confidentially. Maintainers may warn, temporarily ban or permanently ban participants, following the Covenant's enforcement guidelines.
