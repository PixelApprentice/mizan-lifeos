# Name and logo policy

The code is free software. The **name "Mizan"** and the **scales logo** identify the official project. Copyright licences (AGPL and commercial) do not grant rights to them.

**Allowed without asking**
- Saying that your product works with, or is based on, Mizan.
- Packaging **unmodified** Mizan for a Linux distribution, F-Droid or similar, under the name Mizan.
- Writing articles, tutorials and videos about Mizan, and using the logo to refer to the project.

**Ask first**
- Publishing a **modified** build under the name Mizan or with the logo. Forks must use a different name and icon; "Foo, based on Mizan" is fine.
- Using the name in a company, product or domain name.
- Selling merchandise.

## ⚠ Name clearance (maintainer to do before a public launch)

A web check (October 2026) found:
- **"Mizan – Balance Your Life"** on Google Play (`com.musaffotech.mizan_tracker`). This is a productivity, habit and planner app, which is the same market. This conflicts directly on Google Play and is a passing-off risk.
- A **pending US trademark application for "MIZAN"** by QWERTY Options Inc., class 042, covering SaaS for financial market analysis (listed on trademarks.justia.com). It covers a different product, but the same class.

Recommendation:
- Publish under a distinctive mark, for example **"Mizan LifeOS"**, or choose a new name.
- Search USPTO, EUIPO, WIPO and the app stores for that mark in classes 009 and 042 before filing your own trademark.
- Get a trademark lawyer's opinion before spending money on branding.

The Android application id (`com.salahudin.mizan.companion`) and the desktop identifier (`com.salahudin.mizan`) can stay as they are whatever the brand becomes. Changing them after a store release would break updates, so decide **before** the first store upload.
